# P1.1 - MySQL HA Lab: Quick Reference & Test Commands

**Context:** Updated Lab Environment (Custom MySQL Binary + NFS + Pacemaker)
**Nodes:** `db-node1` (10.10.10.110), `db-node2` (10.10.10.120), `nfs1` (10.10.10.200)
**VIP:** 10.10.10.130
**Client:** `db-node` (10.10.10.101)

---

## 1. Cluster Health Checks

### Check Overall Status
```bash
pcs status
```
*Look for: `Online: [ db-node1 db-node2 ]` and `webdb-group` Started on one node.*

### Check Corosync Connectivity
```bash
corosync-cfgtool -s
```
*Look for: `nodeid: 2: connected` (or vice versa).*

### Check Resource Configuration
```bash
pcs resource config webdb-group
pcs resource config p_mysql
```

### Check VIP Location
```bash
ip -br a | grep 10.10.10.130
```
*Should only show output on the active node.*

### Check NFS Mount
```bash
mount | grep mysql_data
df -h /var/lib/mysql_data
```

## 2. MySQL Connectivity Tests

### Connect via VIP (From Client or Passive Node)
```bash
mysql -h 10.10.10.130 -u root -p123 -e "SELECT @@hostname;"
```
*Expected: Returns the hostname of the **active** node (e.g., `db-node1` or `db-node2`).*

### Insert Data via VIP
```bash
mysql -h 10.10.10.130 -u root -p123 -e "INSERT INTO labdb.notes (msg) VALUES ('Test via VIP');"
```

### Read Data via VIP
```bash
mysql -h 10.10.10.130 -u root -p123 -e "SELECT * FROM labdb.notes;"
```

### Check MySQL Process & Port
```bash
ps -ef | grep mysqld
ss -lntp | grep 3306
```

## 3. User Management & Permissions

### Add/Update User Grants (Run on Active Node)
*Use this if you get `ERROR 1130: Host not allowed`.*

```sql
mysql -u root -p123

-- Allow specific hosts (Recommended for security)
CREATE USER IF NOT EXISTS 'root'@'db-node1' IDENTIFIED BY '123';
CREATE USER IF NOT EXISTS 'root'@'db-node2' IDENTIFIED BY '123';
CREATE USER IF NOT EXISTS 'root'@'10.10.10.101' IDENTIFIED BY '123'; -- Client IP
GRANT ALL PRIVILEGES ON *.* TO 'root'@'db-node1' WITH GRANT OPTION;
GRANT ALL PRIVILEGES ON *.* TO 'root'@'db-node2' WITH GRANT OPTION;
GRANT ALL PRIVILEGES ON *.* TO 'root'@'10.10.10.101' WITH GRANT OPTION;

-- OR Allow entire subnet (Lab convenience only)
CREATE USER IF NOT EXISTS 'root'@'10.10.10.%' IDENTIFIED BY '123';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'10.10.10.%' WITH GRANT OPTION;

FLUSH PRIVILEGES;
EXIT;
```

## 4. Failover Testing

### Planned Move (Graceful)
```bash
# Move to db-node2
pcs resource move webdb-group db-node2

# Verify
pcs status
mysql -h 10.10.10.130 -u root -p123 -e "SELECT @@hostname;"

# Clear constraint to allow automatic management
pcs resource clear webdb-group
```

### Standby Node Test
```bash
# Put db-node1 in standby
pcs node standby db-node1

# Verify resources moved to db-node2
pcs status

# Bring db-node1 back
pcs node unstandby db-node1
```

### Cleanup Failed Resources
*Use if a resource shows as `Failed` after a crash.*
```bash
pcs resource cleanup
pcs status
```

## 5. Troubleshooting Commands

### Check MySQL Error Log
```bash
tail -n 50 /var/log/mysql/error.log
```

### Check Pacemaker Logs
```bash
journalctl -u pacemaker -n 50 --no-pager
```

### Verify Firewall Services
```bash
firewall-cmd --list-services
```
*Expected: `mysql high-availability` (on DB nodes), `nfs` (on nfs1).*

### Check NFS Exports (On nfs1)
```bash
exportfs -v
```

### Verify MySQL Binary Paths
```bash
ls -l /usr/local/mysql-8.0.46-linux-glibc2.28-x86_64/bin/mysqld
ls -l /usr/local/mysql-8.0.46-linux-glibc2.28-x86_64/bin/mysql
```

### Check `/home/mysql` Directory
*Fixes `runuser: warning: cannot change directory` errors.*
```bash
ls -ld /home/mysql
# If missing:
mkdir -p /home/mysql
chown mysql:mysql /home/mysql
chmod 700 /home/mysql
```
